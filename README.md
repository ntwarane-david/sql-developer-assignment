# sql-developer-assignment
Assignment 4 
## approach i used
In this assignment, I followed the tasks step by step (Task 1 to Bonus Task).

I created functions and procedures as required in each task.
Each function was tested using:
PL/SQL blocks (DBMS_OUTPUT)
SQL SELECT queries
I reused functions in later tasks instead of rewriting logic.
The bonus task combined all previous functions into one system using a cursor FOR loop.
## Lessons Learned from tasks
From Task 1, I learned how to create a simple procedure that accepts an input parameter and retrieves data from a table.
Task 2, I learned how to update data in a table using a procedure. I practiced retrieving existing values before updating them, then displaying both old and new values.
Task 3, I learned how to use OUT parameters to return multiple values from a procedure. This helped me understand how procedures can send data back to the calling block.
Task 4, I learned how to create procedures that update data in a table and display both old and new values using DBMS_OUTPUT.
Task 5: Learned how to return GPA grades using IF-ELSIF conditions.
Task 6: Learned how to calculate age using MONTHS_BETWEEN and handle exceptions.
Task 7: Learned how to count records using functions and SQL aggregation.
Task 8: Learned how to classify salaries using conditions and return categories.
Task 9: Learned how to use default parameters in functions.
Bonus Task: Learned how to combine all functions in one system using cursors and loops.
